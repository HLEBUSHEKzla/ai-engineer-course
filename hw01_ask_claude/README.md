# ДЗ 1. Запитання до Claude через API

Завдання: створити репозиторій на GitHub, налаштувати venv та IDE, отримати API-ключ і написати Python-скрипт, який відповідає на запитання через API.

Скрипт [`ask.py`](ask.py) надсилає запитання в Claude і друкує відповідь у міру генерації, не чекаючи на повний текст.

Одне запитання:

```bash
python hw01_ask_claude/ask.py "Що таке RAG?"
```

Без аргументів скрипт відкриває чат. Чат пам'ятає попередні повідомлення: `/clear` починає розмову заново, `exit` завершує роботу.

```bash
python hw01_ask_claude/ask.py
```

## Налаштування

За замовчуванням використовується Haiku 5.5 як найдешевша модель ($0.10 за мільйон вхідних токенів і $0.50 за мільйон вихідних). Для цього завдання її цілком достатньо. Розумнішу модель можна задати в `.env`, наприклад `CLAUDE_MODEL=claude-sonnet-5-5` або `claude-opus-5-5`, але вони коштують дорожче.

`CLAUDE_EFFORT` визначає, наскільки ретельно модель обмірковує відповідь: `low`, `medium`, `high`, `xhigh` або `max`. За замовчуванням стоїть `low`. Що вищий рівень, то довша й дорожча відповідь.

Довжина однієї відповіді обмежена 4096 токенами (`MAX_TOKENS` в `ask.py`), щоб одна відповідь випадково не з'їла забагато токенів.
