# ДЗ 1. Питаю Claude через API

Завдання було таке: зробити репозиторій на GitHub, налаштувати venv і IDE, отримати API-ключ і написати Python-скрипт, який відповідає на питання через API. Все зроблено.

Скрипт [`ask.py`](ask.py) відправляє питання в Claude і друкує відповідь одразу, поки вона генерується, а не чекає на повний текст.

Можна задати одне питання:

```bash
python hw01_ask_claude/ask.py "Що таке RAG?"
```

А можна запустити без аргументів, тоді відкривається чат. Він пам'ятає попередні повідомлення: `/clear` починає розмову заново, `exit` закриває чат.

```bash
python hw01_ask_claude/ask.py
```

## Що можна змінити

За замовчуванням стоїть Haiku 5.5, бо вона найдешевша ($0.10 за мільйон вхідних токенів і $0.50 за мільйон вихідних). Для домашки її з головою вистачає. Якщо хочеться розумнішу, можна дописати в `.env`, наприклад, `CLAUDE_MODEL=claude-sonnet-5-5` або `claude-opus-5-5`, але вони дорожчі.

Ще є `CLAUDE_EFFORT`, тобто наскільки старанно модель думає над відповіддю: `low`, `medium`, `high`, `xhigh` або `max`. У мене стоїть `low`. Що вище, то довше і дорожче.

Одна відповідь обмежена 4096 токенами (`MAX_TOKENS` в `ask.py`), щоб випадково не спалити купу токенів.
