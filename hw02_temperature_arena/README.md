# ДЗ 2. Арена температур

Завдання: у новому файлі `arena.py` зробити 2 запити з різною temperature, порівняти відповіді й записати спостереження коментарем.

Скрипт [`arena.py`](arena.py) надсилає той самий промпт двічі: з temperature 0.0 і 1.0. За замовчуванням модель придумує назву для кав'ярні програмістів, але можна передати й власний промпт:

```bash
python hw02_temperature_arena/arena.py
python hw02_temperature_arena/arena.py "Поясни одним реченням, що таке токен у LLM."
```

Результати тестів і висновки записані коментарем у кінці `arena.py`. Коротко: на 0.0 відповідь щоразу однакова, на 1.0 щоразу нова, але з більшою кількістю помилок. На фактичних запитаннях різниця майже непомітна.

## Чому Haiku 4.5, а не 5.5, як у першому завданні

Haiku 5.5 на параметр `temperature` повертає помилку 400: у нових моделях Claude його прибрали. До того ж актуальний SDK `anthropic` (2.x) працює з новою версією API, у якій temperature немає взагалі, для жодної моделі.

Тому в скрипті використано обхідний шлях:
- модель `claude-haiku-4-5`, яка ще приймає temperature (один запуск коштує менше цента);
- стара версія API, яка задається заголовком `anthropic-version: 2023-06-01`;
- temperature передається через `extra_body`, бо окремого аргументу в SDK вже немає.

Ще одна відмінність від слайдів: у Claude temperature змінюється від 0 до 1, а не до 2, як в OpenAI. Тож значення 1.5 тут перевірити не вийде.
