Мій скрипт [`arena.py`](arena.py) шле один і той самий промпт двічі: з temperature 0.0 і з 1.0. За замовчуванням просить придумати назву для кав'ярні програмістів, але можна передати і свій промпт:

```bash

```

Що вийшло, я розписав коментарем у кінці `arena.py`. Якщо коротко: на 0.0 відповідь щоразу однакова, на 1.0 щоразу нова, але з більшою кількістю помилок. А на фактичних питаннях різниці майже нема.

## Чому Haiku 4.5, а не 5.5, як у першій домашці

Спочатку хотів взяти ту саму Haiku 5.5, але вона на `temperature` просто повертає помилку 400. У нових моделях Claude цей параметр прибрали. До того ж свіжий SDK `anthropic` (2.x) працює з новою версією API, де temperature немає взагалі, для жодної моделі.

Тому довелось трохи обійти:
- модель `claude-haiku-4-5`, вона ще приймає temperature (один запуск коштує менше цента);
- вручну ставлю стару версію API, заголовок `anthropic-version: 2023-06-01`;
- temperature передаю через `extra_body`, бо звичайного аргументу в SDK вже нема.

Ще з різниці зі слайдами: у Claude temperature від 0 до 1, а не до 2, як у OpenAI. Тож 1.5 тут не спробуєш.
